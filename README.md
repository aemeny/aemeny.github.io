# Personal Portfolio Website 🌐

Welcome to the repository for my personal portfolio website! This site is designed to showcase my skills, projects, and my journey in game development.

## 🌟 About the Website
Hosted on GitHub Pages, this portfolio highlights:
- My ongoing and completed projects, including shaders, custom game engines, and industry-standard game engine work such as Unity.
- Details about my academic and professional background in game development.
- Insights into my technical expertise, including Unity, OpenGL, and custom game engine development.

## 🛠️ Technologies Used
- **HTML5** and **CSS3** for a clean and responsive design.
- **JavaScript** for interactive elements.
- Hosted using **GitHub Pages** for reliable and accessible deployment.

## 🚀 Features
- Project gallery with descriptions and links to repositories.
- Contact section for networking and collaboration opportunities.
- Optimized for both desktop and mobile users.
